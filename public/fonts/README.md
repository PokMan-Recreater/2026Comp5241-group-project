# Site fonts

These font files are self-hosted. Keep their license files with them.

- `plus-jakarta-sans-latin.woff2`: Plus Jakarta Sans, variable weights 200–800, Latin subset. Retrieved from the [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@200..800&display=swap), version v12. License: `plus-jakarta-sans-OFL.txt`.
- `source-han-sans-cn.woff2`: Adobe Source Han Sans, CN variable subset.
- `source-han-sans-tw.woff2`: Adobe Source Han Sans, TW variable subset.

The Chinese files come from [Adobe's official WOFF2 subsets](https://github.com/adobe-fonts/source-han-sans/tree/release/Variable/WOFF2/OTF/Subset) and use `source-han-sans-LICENSE.txt`.

The Latin font is preloaded. Chinese fonts are selected by the interface or lesson language and use `font-display: swap`.
