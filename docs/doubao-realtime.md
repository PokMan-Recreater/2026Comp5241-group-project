# 豆包实时语音面试（本地版）

## 填写密钥

在项目根目录 `.env.local` 的 `DOUBAO_REALTIME_API_KEY=` 等号后填入**新生成的豆包语音 API Key**，保存后重启 `npm run dev`。不要使用已在聊天中公开的旧密钥。该文件被 Git 忽略，不要将密钥放入 `public/`、截图或提交。

准备页提供6种“面试官风格”：严格追问、温和引导、冷静专业，各配男女声。默认严格追问男声。服务端按公开的固定配置表选择音色，并加入对应风格指令，不接受客户端任意音色或指令。对应表在 `public/interview-personas.js`，音色依据官方 S2S 全双工列表；实际成熟感、音色权限及风格表现仍需真实试听。`DOUBAO_REALTIME_VOICE` 仅用于未传风格的旧客户端。模型或音色无权限时会停止，不会伪造回答。

打开本地 `#mock-interview` 准备页，选择方向、难度和面试语言（仅中文、英文），勾选音频上传同意，点击“开始面试”后跳到独立文档 `/interview-room.html`，再授权麦克风。此时才建立供应商连接，开始产生用量。摄像头仅用于本机预览。界面跟随主站的简中、繁中、英文设置；面试语言初始值跟随界面，仍可独立选择。界面语言会一并传到独立面试室。

面试室为独立全屏页面，无主站侧栏、设置表单和实时转写文字，仅显示面试官、可选本机摄像头、状态与通话控制。文字只在内存中收集，结束屏才提供下载，不在通话中显示。设置及同意通过本标签页 sessionStorage 一次性传递，5分钟过期，进入后立即删除；刷新、直接进入或浏览器返回不会自动重开通话。

界面使用主站浅黄色主题，摄像头预览在面试区域左上角，包括移动版。服务名称文案为“AI 实时语音服务”；实际服务提供商仍是豆包，不因展示名称变化而更换。

## 实现及边界

- 使用新版 Seeduplex JSON WebSocket 协议，不使用旧 O2.0 RTC 智能体页面，也不需要旧版 AppId/Token。
- 浏览器通过同源 WebSocket 连接本地 Node 服务，再由服务端携带 `X-Api-Key` 连接固定的豆包端点。状态接口不返回密钥。
- 输入单声道 16kHz int16、小端 PCM，每包 20ms；AudioWorklet 重采样。输出 24kHz pcm_s16le，在浏览器实时播放。不使用浏览器朗读或假转写。
- 静音使用官方静音事件；手动打断和用户开口都会清理本地播放队列。结束、断网、离开或页面进入后台会释放麦克风、摄像头和连接。不自动重连。
- 本地一次只允许一场通话，每场最长 10 分钟；这些是用量保护，**不是免费保证**。无法查询免费余额，超额可能计费。请同时在控制台核对额度和费用提醒。静音并不结束计费。
- 不设置问题数或轮数，保留10分钟安全时长上限。8分30秒提醒收尾并通知模型不要再开新问题，9分30秒整理复盘，剩余时间留给总结；10分钟仍强制关闭，不能无限延长计费。主动结束也进入收尾，并提供“立即退出”。
- 面试进行中不挂评分工具、不逐轮生成报告，只进行自然问答。点击结束或到达收尾阶段后，才通过 `session.update` 给同一语音模型加入一次性评分工具及完整回答参考；收到更新确认后提交剩余音频以触发最终处理，无需另一个API Key。不发送未经官方文档支持的 `response.create` 事件。评分等待只发生在结束阶段，最多20秒，并为最后提示留出时间，10分钟总上限不变。
- 服务端核对引用、原回答、评分维度范围后接受报告；结束页展示评分维度（含引用和理由）、优点与需补足的证据，支持下载。实时模型的工具调用有时只返回 summary、score 和 rewrite，缺失的定性段落不会伪造：优点/改进由已核验的评分维度生成，缺失的改写或下一步练习直接不显示。校验失败或模型未返回时，明确标为本地规则建议，不伪造AI分数。未完成转写不作为完整回答计分。实时通话中“会话更新 + 提交剩余音频”能否稳定触发最终工具调用仍需真实通话继续观察；后台评分已用真实供应商验证。
- 后台评分（`scripts/interview-cloud-review.mjs`）领取 Supabase 任务后，先用同一豆包密钥合成一句很短的语音指令，作为真实输入音频送入独立实时会话，再等待 `update_interview_review` 工具调用。实测保存 → 领取 → 评分 → 写回报告约 29 秒，任务状态 completed，模型版本 doubao-seeduplex-1.2.6.1；引用不匹配时任务重试，不写入假分数。
- 评分与保存字段详见 `docs/interview-data-requirements.md`。面试会话、对话轮次、评分与复盘任务现已保存到 Supabase，并可按账号隔离读取与删除。项目背景仍用于具体追问，未提供时才邀请介绍项目。
- 本地 WebSocket 服务不是 Vercel 普通函数。线上仍保留原面试模式，未上传或部署。生产接入须另备常驻 WSS 后端、用户鉴权及每用户限额；不能把本地后端直接公开。
- 自动测试只使用本地供应商替身，不消耗真实额度。真实鉴权、模型权限、麦克风和端到端对话需要配置密钥后由用户点击测试。
