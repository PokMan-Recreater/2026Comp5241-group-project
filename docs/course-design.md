# 课程重做说明

本轮范围是课程及支撑这些课程的学习活动。不包含账号认证、共享数据库或真实跨学生分析的建设。保留已确认的黄与浅紫网页风格，以及默认英语、简体中文、繁体中文。

## 课程与成果

| 课程 | 案例 | 主要成果 |
| --- | --- | --- |
| 软件开发：从需求到发布 | 校园二手书服务 | 首版范围、开发流程、试用与版本复盘 |
| 需求分析与用户访谈 | 活动室预约 | 访谈追问、冲突记录、验收场景、需求交接 |
| 网页系统、数据与权限 | 失物认领 | 请求路径、数据关系、权限规则、失败路径 |
| 与 AI 编程助手一起开发 | 报名导出去重 | 委托说明、可运行函数、反例、审查记录 |
| 测试、故障与上线决定 | 售票故障及发布 | 缺陷单、测试表、两种上线方案、恢复说明 |
| 产品范围与团队沟通 | 午餐订单变更 | 方案成本比较、协商回复、实施交接 |
| 在技术面试中讲清自己的工作 | 已完成练习或个人作品 | 项目介绍、设计回答、书面模拟面试、修改记录 |

共 7 门、28 节。每节有分段讲解、进阶分析、一份三部分作业、参考解答、自查依据。学习时长是包含阅读和练习的估计，不是观看时长或完成保证。

## 内容原则

- 从收到的材料、实际步骤、错误例子或冲突开始讲，避免先讲口号。
- 提供可讨论的案例细节，包括时间边界、数据关系、重复请求、成本、缺失证据。
- 把观察、假设、政策和建议分开。案例、人物、数字均为虚构教学材料，不伪装成真实访谈或运营数据。
- 开放作业给出一种合理参考及检查依据，不声称只有唯一措辞；不按字数或关键词制造掌握分数。
- 讲解可以完整阅读，关键任务可修改、保存、下载，不能以“点完成”替代课程成果。
- 面试课程不声称评估就业资格，不虚构履历；使用课程练习时应明确标注。
- 中文与英文分别编写；繁体通过 OpenCC 生成后检查技术词和歧义转换，统一反馈、线下、帖子等词。后续仍适合由真实学习者试读修订。

## 活动及准确边界

| 活动 | 本轮实现 |
| --- | --- |
| 图文阅读与例题 | 结构化阅读、原创建模示意、案例与参考解法 |
| 分步演示 | 开发流程、请求路径的四阶段演示；切换阶段对应讲解文字 |
| 旁白 | 设备文字转语音并保留文字稿；明确标注不是 AI 生成配音 |
| 案例访谈 | 可展开的多方访谈材料，各方问题、证据、冲突不同；明确标注为编写的材料 |
| 实时 AI 角色对话 | 已支持读取当前课程与角色，不再固定扮演演唱会主办方；仍需服务端 AI 密钥才能使用 |
| 模拟面试 | 四个书面问题及对应追问，作业可保存；实时 AI 面试同样需要连接 |
| 权限实验 | 改变模拟请求者、动作与物品状态，按确定规则判断；不代表新增真实账号系统 |
| 范围实验 | 选择变更组合，检查六点预算及未决政策；不伪装成开发工时预测 |
| 在线编程 | 两个代码课节，共用明确的函数约定；保留正确参考实现、错误 Map 修复稿及隔离限时运行 |
| 游戏 | 复用预算内的售票上线模拟，在课程中加入两次运行比较与模型局限讨论；数字是模型输出 |
| 作业与反馈 | 28 份三部分作业、参考解答、自查清单；部分课节提供带逐项解释的理解检查 |

AI 教学和个性化内容是老师的明确要求，但本轮不能把未配置的 AI 入口算成已经联调。AI 生成旁白也未完成。身份与共享教学班数据维持原型边界。

## 课程组织参考与技术核对

本轮借鉴真实开放课程组织材料、例子、练习和反馈的方式，没有复制课程讲义或作业。此处是由 AI 协助编写的原创课程草稿，不能冒称由真人教师讲授或已通过教师审核。

- [Full Stack Open：Fundamentals of Web apps](https://fullstackopen.com/en/part0/fundamentals_of_web_apps)：用具体请求过程连接解释与图示。
- [CS50：Problem Set 1](https://cs50.harvard.edu/x/psets/1/)：题目约定、示例与独立检查的组织方式。
- [The Carpentries：Preparing to Teach](https://carpentries.github.io/instructor-training/instructor/18-preparation.html)：学习目标和形成性检查。
- [MDN：Set](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)、[Map](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Map)：集合行为、原对象引用、键值覆盖；不将特定运行时的性能期望说成所有实现的绝对保证。
- [OWASP：Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)：权限需逐次请求检查。
- [Pro Git：Contributing to a Project](https://git-scm.com/book/en/v2/Distributed-Git-Contributing-to-a-Project)：小范围、可审查的协作改动。

教师项目说明的对应关系：第 1 页的三类主题、不同学习背景、互动活动、个性化教学与教师定制。7 门课及具体案例是本项目方案，不是教师规定的数量或名称。

## 文件与维护

- `course-authoring/curriculum.py`：英、简中原稿及繁体生成规则。
- `course-authoring/requirements.txt`：仅文案生成时使用的依赖。
- `public/curriculum.js`：生成好的三语内容，网页运行与 Vercel 构建不依赖 Python 或 OpenCC。
- `public/learning-studio.js`：安全阅读渲染、作业、案例、理解反馈和规则实验。

作业、检查结果、笔记和已有学习记录保存在本机原型中，修改语言不会清除作业。旧的三门内置课程保留课程编号及课节编号，个人编辑的课程不会被静默覆盖；如本机有旧版内置课程的编辑副本，它仍优先于新版内置内容。

不自动清空旧进度。旧完成状态只是学习者历史确认，不证明已掌握重做后的内容，建议重新阅读并完成新作业。

重新生成文稿时，在独立文案环境安装 `course-authoring/requirements.txt` 后运行 `python course-authoring/curriculum.py`。普通运行只需 Node.js。
