# 教师课程制作与班级追踪实施方案

2026-11-03，基于当前 Forma 代码检查。此文档为实施规划，未创建以下业务表、未启用新 AI 服务。

## 当前真实状态

- Supabase 账号身份已具备 student、teacher、admin；访客身份下拉不再承担权限功能。
- `public/app.js` 的 teacherPage/editorPage/newCourse 是旧版课程编辑路径；allCourses 会把非 storyboard 的课程标记为 retired，因此不能直接当作现有 45 节动画课程的完整编辑器。
- classroomsPage/import-form 保存的是浏览器内名单，仍使用 name/email；新系统应改用学生账号匹配，不需要邮箱。
- analyticsPage 读取当前浏览器 progress/events，不能代表各学生的真实参与情况。
- `api/ai.js` 已有生成课程的兼容接口，但只返回标题、描述、课文等，尚无活动 schema、定向修改、教师鉴权和云端发布流程。

## Claude 现有制作方式

项目中的 `.claude/skills/run-forma/SKILL.md` 是启动、构建、测试和播放器截图说明，不是网站可直接调用的课程生成服务。本次搜索未找到专用于制作这些网页课程的独立 skill。

当前动画课程注册在 `public/all-lessons.js`；正文和分镜在 `public/lessons-*.js` 等模块；`public/lesson-art-kit.js` 提供插画组件；播放器复用；音频由 `scripts/synthesize-course-narration.mjs` 和 manifest 管理。`course-authoring/curriculum.py` 是旧课程稿件到 JS 的作者工具，不能直接覆盖新的动画课程。

可借鉴的流程是统一结构、复用图形组件、按小节生成、逐节校验、独立生成配音。不能把开发助手的 skill 当成部署后的 AI API。

## 教师工作流程

1. 我的课程：现有官方课程 → 创建教师自己的副本；自己的课程 → 继续编辑。
2. 编辑：课程目标、受众、难度、语言、章节和小节。每小节编辑讲解、例子、分镜和活动。
3. AI 操作：生成目录、生成所选小节、重写所选内容、补例子、调整难度、生成选择题、生成带测试用例的编程题、翻译。先显示候选结果和改动范围，再由教师采纳。
4. 新课程：教师输入主题、教学要求、已有材料；先生成可修改的大纲，再按节生成内容和活动，避免一条请求生成整门课程。
5. 预览与发布：草稿 → 检查 → 预览 → 发布版本。学生学习时绑定已发布版本，修改内容先形成新草稿，不改写学生已经提交的答案。
6. 我的班级：创建班级、分配课程版本、粘贴或 CSV 导入 student01 等学生账号。只匹配实际存在的学生账号，报告重复、无效和不存在的账号；不根据导入内容创建管理员或老师。
7. 班级概览：按学生和课程查看进度、有效学习时间、最近活动、答题次数、正确率、编程测试结果、Hint 使用次数及完成情况，支持导出。

普通注册永远为学生。老师只能编辑自己的副本、管理自己的班级、查看自己班级中的学习数据；学生只能访问已分配课程和自己的作答。教师统计默认不包含私人 AI 面试逐字记录。

## 内容与动画结构

课程 → 发布版本 → 小节 → 分镜步骤 → 活动。

每个分镜保存正文、讲稿、时长、结构化 scene 参数、可选音频资源。scene 仅允许预先实现的组件类型，如流程、前后对比、时间线、角色任务、数据流、状态变化；参数有长度、数量及布局限制。保留已有手写 SVG 动画作为官方课程的专用组件，教师改写对应文字不自动改坏原动画；更换场景需选择另一个兼容模板。

AI 只生成经过校验的数据，不执行 AI 返回的 JS、HTML、SVG 或任意脚本。通用模板支持自动排布和中英文字数限制；新主题若确实需要新动画机制，应由开发者补组件，而不是承诺免费模型能生成任意可靠动画。

活动先支持选择题、带标准输入输出/函数契约与边界测试的编程题。保留用户“不用简答题”的要求。已有模拟活动可作为受控参数的可选组件，不自动生成无法验证的模拟机制。答案和判题测试放服务端；Hint 是明确提供参考答案，记录使用次数。

## 最小数据库与事件

- teacher_courses：owner_teacher_id、官方来源、标题、当前草稿/发布版本。
- course_versions：结构化正文和活动、schema_version、revision、draft/published、发布时间。
- classrooms：owner_teacher_id、名称。
- classroom_members：classroom_id、student_id，唯一约束。
- course_assignments：classroom_id、course_version_id、可选截止时间。
- learning_events：student_id、assignment_id、lesson_id、事件类型、幂等 event_id、服务端接收时间、有效心跳间隔。
- activity_attempts：student_id、assignment_id、activity_id、attempt_id、提交内容、服务端核验结果、Hint 标记。
- generation_jobs：teacher_id、course_id、生成范围、状态、尝试次数、用量、错误码；只在需要后台生成时增加。

学习进度从真实完成事件和判题结果计算，学生不能直接提交“100%完成”或任意正确分数。页面可见且有近期交互时发送心跳；隐藏页面停止累计，心跳间隔设上限、重试去重。时间是参与指标，不等同于专注程度或掌握程度。

## 免费 AI 接入建议

优先核实并接入智谱 BigModel 的 `glm-4.7-flash`：官方公告说明免费调用，官方文档支持结构化输出和兼容 chat/completions 接口。免费不代表无限并发、恒定响应时间或未来永不调整；实际额度以该账号控制台为准。

服务端配置：

```
AI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
AI_MODEL=glm-4.7-flash
AI_API_KEY=在 .env.local 或 Vercel 环境变量填写
```

不把密钥放入浏览器。现有 AI 接口先增加教师会话鉴权、课程所有权检查、按账号限额、固定模型和结构校验，再用于正式制作。关闭免费模型失败后自动转付费模型的逻辑；失败保留草稿，允许重试。课程生成仅发送教师选择的教学材料，不附学生名单、私人面试内容或作答记录。

免费文本模型只覆盖课程文字、活动、讲稿、翻译、模板参数生成。语音配音单独计费/抵扣语音额度；已有音频缓存复用。繁体可复用普通话配音，英语单独生成音轨。免费文本 API 不包含任意图像、视频或语音生成。

## 实施顺序与验收

第一阶段：课程副本、手动编辑、版本发布和权限。验收：teacher01 修改副本不改变官方课，teacher02 不能覆盖，学生只能读发布版本。

第二阶段：免费 AI 生成一个小节与活动，差异预览、采纳、错误重试。验收：结构/答案检查通过、同样内容可在三个界面语言下预览、不执行模型生成的任意代码。外部 API 必须有真实密钥后再做联调，不标记为已接通。

第三阶段：学生账号导入、分配和进度。验收：导入 student01/student02，分别在真实登录会话学习/提交，老师看到不同记录；其他班级无权限读取。

第四阶段：有效时间、活动明细、CSV 导出与批量生成。验收：后台停留不累计、重试不重复、批量任务按节检查并保留成功结果，不因一次失败重做整门课。

## 本次落地结果

教师工作台、单节智谱生成与预览采纳、课程版本发布、真实学生账号导入、课程分配、学生选择题判题和教师参与统计已实现。五张教学业务表已在用户当前 Supabase 项目安装，真实跨账号链路通过。文本模型联调成功，首次429后手动重试成功；未开通任何新付费服务。

阶段范围明确：当前支持文本＋三类受控场景＋选择题；不是任意专用动画自动生成器。新增配音、编程题编辑/执行以及批量后台生成队列仍为后续工作。对既有官方动画课程的改编生成独立文本与模板副本，不直接编辑官方手写动画。
